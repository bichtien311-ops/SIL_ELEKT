# Лабораторная 12. Трёхфазный инвертор и спектр напряжения

**Тема:** Трёхфазный мостовой инвертор с SPWM (и SVPWM), анализ гармоник.

## Цель
Сформировать трёхфазную систему напряжений, исследовать спектр фазного и линейного напряжения, сравнить использование DC-шины при SPWM и SVPWM.

## Инструменты
- MATLAB/Simulink (Three-Phase Inverter, PWM Generator (3-Level/2-Level), FFT).

## Задание
1. Соберите трёхфазный 2-уровневый инвертор с RL-нагрузкой (звезда).
2. Реализуйте SPWM (три синусоиды 50 Гц, m_f = 21). Снимите фазное и линейное напряжение, токи фаз.
3. Выполните FFT линейного напряжения, измерьте U_1 и THD.
4. Измерьте максимально достижимое U_л при m_a = 1.
5. (Доп.) Включите SVPWM, повторите измерения, сравните максимальное U_л и THD.

## Расчётная часть
| Метод | U_л1 (m_a=1) расчёт | U_л1 сим. | THD тока |
|-------|---------------------|-----------|----------|
| SPWM | ≈0.866·U_dc | | |
| SVPWM | ≈U_dc | | |

## Контрольные вопросы
1. На сколько процентов SVPWM повышает выходное напряжение?
2. Почему линейное напряжение «чище» фазного по гармоникам?
3. Как мёртвое время проявляется в токах фаз?

## Форма отчёта
Цель → схема → осциллограммы фаз/линейных → спектры → сравнение SPWM/SVPWM → выводы.
