# Лабораторная 16. Преобразователь для PV / электропривода

**Тема:** Моделирование прикладной системы — MPPT-преобразователь PV или частотный пуск АД.

## Цель
Применить изученные топологии к реальной задаче: реализовать MPPT для PV-панели ИЛИ частотный пуск асинхронного двигателя по закону U/f.

## Инструменты
- MATLAB/Simulink (Simscape Electrical: PV Array, Asynchronous Machine, инвертор).

## Вариант A — PV + MPPT
1. Соберите модель PV-панели, Boost-преобразователь, нагрузку (DC-шина).
2. Реализуйте алгоритм MPPT (P&O — «возмущение и наблюдение»).
3. Подайте изменение освещённости, проверьте слежение за точкой максимальной мощности.
4. Сравните отдаваемую мощность с/без MPPT.

## Вариант B — Электропривод U/f
1. Соберите: DC-шина → трёхфазный инвертор (SPWM) → асинхронный двигатель.
2. Реализуйте закон U/f = const, задайте разгон частоты 0 → 50 Гц.
3. Снимите скорость, ток статора, момент при пуске.
4. Сравните прямой пуск и частотный по пусковому току.
