# Лабораторная 08. Анализ гармоник и активный PFC

**Тема:** Измерение THD и PF выпрямителя, моделирование Boost-PFC.

## Цель
Оценить качество потребляемого тока диодного выпрямителя с C-фильтром и показать улучшение при активной коррекции коэффициента мощности.

## Инструменты
- MATLAB/Simulink (FFT Analysis в Powergui) — предпочтительно.
- LTspice (.four для спектра).

## Задание
1. Соберите однофазный мост + C-фильтр (из ЛР-07). Снимите ток сети i_с(t).
2. Выполните FFT-анализ тока: измерьте THD, амплитуды гармоник, PF.
3. Соберите **Boost-PFC**: мост → Boost-каскад с управлением током по форме напряжения сети (average current mode).
4. Снимите i_с(t) после PFC, выполните FFT, измерьте THD и PF.
5. Сравните спектры «до» и «после» PFC.
